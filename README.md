# BT24 - Bootstrap Login Form

Bài thực hành sử dụng Bootstrap để xây dựng form đăng nhập.

## Nội dung
- Bootstrap 5 qua CDN
- Form đăng nhập gồm Email, Password, Remember me
- Nút Sign in
- CSS căn giữa form trên màn hình
- Logo Bootstrap dạng SVG

## Cách chạy
Mở file `index.html` bằng trình duyệt hoặc Live Server trong VS Code/WebStorm.

## File
- `index.html`
- `styles.css`
- `bootstrap.svg`
